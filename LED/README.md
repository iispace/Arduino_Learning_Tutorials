# LED란?

- [LED(Light Emitting Diode)](https://ko.wikipedia.org/wiki/%EB%B0%9C%EA%B4%91_%EB%8B%A4%EC%9D%B4%EC%98%A4%EB%93%9C): 순방향으로 전압을 가했을 때 발광하는 반도체 소자
- 일반적인 다이오드와 동일하게 극성을 가지며, 캐소드(음극)에서 애노드(양극)로 정전압을 가해서 사용
- P형 반도체는 양공(hole)이 많은 영역으로, 전류가 흐를 때 전자와 재결합하여 빛을 방출하며, N형 반도체는 전자(electron)이 많은 영역으로, 전류가 공급될 때 전자가 P형으로 이동
- 전압을 걸면, 전류가 N형 -> P형 방향으로 흐르게 되고, 이 때 이동하는 전자는 P형의 양공(hole)과 만나 재결합하면서 에너지를 방출하게 되는데, 그 에너지가 빛(광자)의 형태로 나오는 것이 LED의 원리
- LED에서 방출되는 빛의 색(파장)은 LED에 사용된 반도체 재료의 밴드갭 에너지에 따라 결정된다. 즉, 어떤 반도체를 쓰느냐에 따라 LED의 색이 달라지는 것.
- 전압이 낮은 동안은 전압을 올려도 거의 전류가 흐르지 않고, 발광도 하지 않음. 그러나, 어느 전압 이상이 되면 전압 상승에 대하여 전류가 빠르게 흘러서, 전류량에 비례해서 빛 발생. 이 전압을 순방향 강하전압이라고 하고, 일반적인 다이오드와 비교해서 LED는 순방향 강하전압이 높음.
  - 빨간색(610 < λ < 760), 오렌지색(590 <λ< 610), 노란색(570 < λ < 590), 초록색(500 < λ < 570)에서는 2.1V 정도.
  - 빨간빛을 내지 않는 것은 1.4V 정도
  - 백색(Broad Spectrum)과 파란색(450 < λ < 500)은 3.5V 정도
  - 고출력 제품은 5V 전후인것도 있음.
  - LED가 빛을 낼 때 소비 전류는 표시등 용도에서는 수 mA ~ 50 mA정도이지만, 조명 용도에서는 소비 전력이 수W단위의 대출력 LED도 판매되고 있어 구동 전류가 1 A를 넘는 제품도 있음
  - 역방향으로 전압을 가하는 경우의 내전압은 일반적인 실리콘 다이오드 보다 더 낮고, 보통은 -5V 정도이며, 이것을 넘으면 소자가 파괴됨.
    - 역방향 내전압: 역방향으로 전압을 걸었을 때, 소자가 파괴되지 않고 견딜 수 있는 최대 전압. 역방향 전압이 너무 높아지면, PN 접합이 파괴되며 큰 전류가 흐르게 되므로 LED가 손상됨. 
-  형광등이나 백열등같은 다른 대다수 광원과 다르게 불필요한 자외선이나 적외선을 포함하지 않는 빛을 내므로, 자외선에 민감한 문화재나 예술 작품이나 열조사를 꺼리는 물건의 조명에 사용
-  입력 전압에 대한 응답이 빨라서 통신에도 사용되고, 조명으로 사용할 경우는 점등하자마자 최대 빛의 세기를 얻을 수 있음.
