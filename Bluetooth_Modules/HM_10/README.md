(3) Serial Monitor에서 시리얼 포트 연결

  - 명령어인 "AT" 입력 후 엔터 키 입력하여 "OK" 응답 확인
  - 버전을 확인하는 명령어인 "AT+VERSION" 입력 후 엔터 키 입력하여 firmware 버전 확인
  - 지원하는 명령어 목록을 확인하는 명령어인 "AT+HELP" 입력 후 엔티 키 입력하여 사용 가능한 명령어 확인
